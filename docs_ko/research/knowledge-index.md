# 연구 지식 인덱스 — 한국어 안내

SchemaRouter의 연구 위키는 별도 GitHub Wiki가 아니라 Git으로 관리하는
`docs/research/`, `docs_ko/research/`, 실험 원장과 GitHub Issues입니다.

**[연구 통합 인덱스(영문 원본)](../../docs/research/knowledge-index.md)** 에서
연구 주제별 **근거 문서 → 코드·연동 → 이슈**를 연결합니다.
이 페이지는 한국어 길잡이이며 실험 수치나 결론의 별도 원본이 아닙니다.

## 새 개발 세션의 확인 순서

1. [연구 프로그램](research-program-2026.md)에서 현재 가설과 우선순위를 확인합니다.
2. [연구 운영 규칙](governance.md)의 세션 재개 및 실험 사전 등록 규칙을 따릅니다.
3. [오픈소스 조사 및 의사결정](tool-routing-landscape.md)에서 이미 검증·기각한 접근법을 확인합니다.
4. [영문 통합 인덱스](../../docs/research/knowledge-index.md)의 주제 ID로 원본 근거와 구현을 찾습니다.
5. [실험 원장](../../benchmarks/research-experiment-ledger.json)과 실제 이슈·PR·CI 상태를 대조합니다.

**주의:** 개발용 데이터에서의 개선, CI 통과, 코드 병합은 독립 평가 통과나
제품 기본값 승인을 의미하지 않습니다. 확인되지 않은 구현 연결은
'미검증'으로 남기고, 부정적 실험 결과도 보존합니다.

관련 정리 작업: [#1712](https://github.com/JDeun/SchemaRouter/issues/1712).
