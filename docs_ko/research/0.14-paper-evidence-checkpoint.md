# SchemaRouter 0.14 논문 근거 체크포인트

> 상태: 2026-10-02  
> 범위: 이미 terminal 상태이거나 protocol이 동결된 근거. 진행 중인 실험의 결과는 partial row에서 추론하지 않습니다.

이 문서는 Issue #199를 위한 논문 준비 체크포인트입니다. `docs/research/paper-evidence-package.md`와 machine-readable `benchmarks/research-experiment-ledger.json`을 보완합니다. 실험 사실의 canonical source는 ledger입니다.

## 1. 주장 계층

0.14 cycle에서는 서로 합쳐서 해석해서는 안 되는 여러 근거 수준을 구분합니다.

| 근거 수준 | 작업 항목 | 허용되는 해석 |
| --- | --- | --- |
| Retrieval mechanics | #418 / #420 Phase A | 동결된 23-task surface에서 Recall@K와 serialized tool-schema compression |
| Small-agent mechanism | #420 B1 | Qwen3-0.6B에 대한 통제된 sanity/reproducibility 근거 |
| Strong-agent replication | #423 B2 | 해당 mechanism이 소형 Qwen3 runtime에만 특화되지 않았다는 근거 |
| Optimization ablations | #430 및 structural K3/K5 | candidate depth / representation 최적화만 해당하며 실패 후보를 사후 수정하지 않음 |
| Corrective retrieval | #431 | typed observable execution state가 bounded re-retrieval을 개선하는지 여부. 현재 active |
| Large held-out generalization | #432 | heterogeneous task/language/catalog 전반의 광범위한 일반화 주장을 하기 전에 필요 |
| Final-answer factual quality | #424 | factual answer quality, units, provenance가 보존/개선된다고 주장하기 전에 필요 |
| Output-field projection | #506 / #510 | 별도의 field-level 질문. 현재 successor runtime qualification은 instrument 근거이지 projection 근거가 아님 |

기본 원칙은 다음과 같습니다. DEV 또는 mechanism pass는 generalization claim이 아니며 infrastructure failure는 scientific negative result가 아닙니다.

## 9. Authority / verifier architecture

```text
user request
    |
    v
registered OpenAPI / MCP / Python / typed source contracts
    |
    v
typed capability registry  <-----------------------------+
    |                                                     |
    v                                                     |
bounded candidate retrieval / re-retrieval                |
    |                                                     |
    |  model may rank / select / abstain / veto           |
    |  only among registered authority                    |
    v                                                     |
local schema + argument + policy + availability gates     |
    |                                                     |
    v                                                     |
authorized tool execution                                 |
    |                                                     |
    v                                                     |
typed observation / projected declared fields ------------+
    |
    v
final answer
```

Model은 executable route, field, argument authority 또는 pseudo-capability를 만들지 않습니다. Corrective retrieval은 observable typed execution state에 따라 candidate exposure를 바꿀 수 있지만 execution authority는 local registered authority에 남습니다.

## 11. 논문 마감 전 남은 근거

다음 항목은 명시적으로 incomplete 상태를 유지해야 합니다.

- #431 terminal aggregate 및 preregistered promotion boolean
- 자동 동결된 #432 held-out condition manifest
- 전체 #432 780-task held-out aggregate 및 statistical interval
- #424 final-answer factual/value/unit/provenance aggregate
- infrastructure-only recovery 이후 #510 runtime-qualification terminal selector
- #510 successor projection 결과 및 gate가 허용하는 경우 후속 confirmation
- 최종 promoted line의 전체 per-language / per-route / per-family paper slice
- protocol이 아직 blocked인 final calibration/blind evidence

진행 중인 job의 partial workflow row에서 pending 항목을 채우거나 결과를 추론해서는 안 됩니다.
