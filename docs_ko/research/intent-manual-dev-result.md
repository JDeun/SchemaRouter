# Intent manual DEV 결과

manual intent DEV track은 unsupported/no-route와 supported operation을 더 잘 분리하기 위한 routing 표현과 threshold를 개발 데이터에서 평가한 기록입니다.

이 결과는 candidate selection/calibration을 위한 DEV evidence이며 fresh holdout claim이 아닙니다. DEV에서 좋아진 rule은 별도 frozen confirmation을 통과하기 전 production default로 승격하지 않습니다. false-route를 줄이는 것과 supported-route recall을 유지하는 것을 함께 평가합니다.
