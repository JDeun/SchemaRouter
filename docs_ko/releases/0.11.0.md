# SchemaRouter 0.11.0

product-first typed capability retrieval release입니다. side-effect 없는 public `retrieve/aretrieve`와 binding readiness를 요구하는 `retrieve_executable/aretrieve_executable`을 도입했습니다. CapabilityCandidate는 full effective schema, field/parameter, semantic/unit/provider/policy/fingerprint contract를 보존합니다.

## 호환성과 신뢰 경계

SchemaRouter는 pre-1.0 정책을 따릅니다. remote schema나 model output은 execution authority를 부여하지 않으며 credential, policy, approval, schema/fingerprint validation은 trusted local boundary에 남습니다. 해당 release의 세부 변경과 migration 정보는 repository `CHANGELOG.md` 및 versioning 문서를 함께 참고하세요.

## 설치

```bash
pip install "schemarouter==0.11.0"
```
