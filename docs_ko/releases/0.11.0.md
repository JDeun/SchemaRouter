# SchemaRouter 0.11.0

SchemaRouter 0.11.0은 **product-first typed capability retrieval release**입니다.

Package는 진행 중인 routing research와 독립적으로 사용할 수 있습니다. Application은 OpenAPI, MCP, OPTIMADE, Python 또는 plugin-defined capability를 등록하고 external agent를 위한 compact typed candidate set을 retrieve하면서 validation/policy/execution authority는 SchemaRouter 내부에 유지할 수 있습니다.

## First-class Top-K capability retrieval

주요 추가 기능은 tool을 실행하지 않는 public retrieval surface입니다.

```python
candidates = router.retrieve(
    "current Young's modulus for MAT-7",
    k=5,
)

for candidate in candidates.candidates:
    print(candidate.route_id)
    print(candidate.parameters)
    print(candidate.output_fields)
```

Async caller는 `aretrieve`를 사용합니다.

현재 local execution binding readiness도 필요하면:

```python
candidates = router.retrieve_executable(query, k=5)
```

또는 `aretrieve_executable`을 사용합니다.

## Candidate가 포함하는 것

`CapabilityCandidate`는 하나의 registered endpoint에 연결되며 다음을 담을 수 있습니다.

- route/tool/endpoint identity
- typed parameter contract와 full effective input JSON Schema
- output field와 full effective output JSON Schema 및 datatype/shape
- semantic ID
- 선택적 원본 단위·표준 단위 정규화 메타데이터·한정 조건
- provider/access/source/license metadata
- read-only/destructive classification
- tool/endpoint fingerprint
- deterministic ranking evidence

Result는 detached snapshot입니다. 반환 candidate를 mutate해도 registry는 변하지 않습니다.

## Retrieval은 execution authority가 아님

`retrieve()`는 의도적으로 side-effect free입니다.

```text
query
  -> SchemaRouter Top-K registered capabilities
  -> downstream LLM/agent selects among them
  -> SchemaRouter validation + policy
  -> trusted execution
  -> typed result
```

SchemaRouter는 hidden pseudo-tool을 노출하거나 route를 만들어내거나 retrieval confidence가 local execution policy를 우회하게 하지 않습니다.

Plain `retrieve()`는 capability contract가 registered됐다는 뜻이며 local invoker가 현재 bound라는 뜻이 아닙니다. `retrieve_executable()`은 readiness requirement를 추가합니다.

## Stable product boundary

0.11.0은 0.10.0의 기존 product capability를 유지합니다.

- 타입이 지정된 도구·엔드포인트·매개변수·필드 레지스트리
- OpenAPI, MCP, OPTIMADE, Python ingestion
- field-first planning과 multi-provider field coverage
- 입력 및 투영 이전 원시 출력의 JSON Schema 검증
- binding/schema drift protection
- read/write/destructive policy와 approval gate
- bounded retry, health, fallback
- explicit field projection과 trusted unit normalization
- 동기·비동기·배치·스트리밍 처리와 타입 기반 이벤트·추적
- SQLite persistence/inspection
- 선택적 LangChain·LangGraph·LlamaIndex·System One/Jev·Laya·Ollama·OpenTelemetry 연동

## Research는 stable library의 downstream

Active 0.14 research는 compact typed retrieval이 full tool catalog 노출 대비 downstream agent utility를 보존/개선하는지 묻습니다.

중요하지만 usable library publication의 prerequisite는 아닙니다. B1/B2 replication, answer-quality, adaptive shortlist depth, state-aware corrective re-retrieval, larger held-out generalization, typed-representation ablation은 별도 evidence track으로 계속됩니다.

Research result가 stable package를 block하는 경우는 reproducible product correctness/security/policy/execution-authority/API-integrity/packaging defect를 드러낼 때뿐입니다.

## Compatibility

새 retrieval API는 additive입니다. 기존 planning/execution API는 의도적으로 변경하지 않습니다.

SchemaRouter는 **Beta / pre-1.0**입니다. 향후 1.0은 한 research cycle 완료가 아니라 explicit long-term public API compatibility commitment를 의미해야 합니다.

## Release validation

Protected release pipeline은 Python 3.10–3.14, Windows, minimum dependencies, type checking, branch coverage, wheel/sdist installation, optional integrations, docs, CodeQL/security, SBOM/provenance, exact post-publication PyPI artifact digest를 검증합니다.
