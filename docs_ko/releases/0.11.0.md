# SchemaRouter 0.11.0

SchemaRouter 0.11.0은 **product-first typed capability retrieval release**입니다.

Package는 진행 중인 routing research와 독립적으로 사용할 수 있습니다. Application은 OpenAPI, MCP, OPTIMADE, Python 또는 plugin-defined capability를 등록하고 external agent용 compact typed candidate set을 retrieve하면서 validation/policy/execution authority는 SchemaRouter 내부에 유지할 수 있습니다.

## First-class Top-K capability retrieval

핵심 추가 사항은 tool을 실행하지 않는 public retrieval surface입니다:

```python
candidates = router.retrieve(
    "current Young's modulus for MAT-7",
    k=5,
)

for candidate in candidates.candidates:
    print(candidate.route_id)
    print(candidate.parameters)
    print(candidate.output_fields)
```

Async caller는 `aretrieve`를 사용합니다.

Application에서 현재 local execution binding readiness도 필요한 경우 다음을 사용합니다:

```python
candidates = router.retrieve_executable(query, k=5)
```

or `aretrieve_executable`.

## Candidate에 포함되는 정보

A `CapabilityCandidate` is tied to one registered endpoint and can carry:

- route/tool/endpoint identity;
- typed parameter contracts and the full effective input JSON Schema;
- output fields plus the full effective output JSON Schema and datatype/shape;
- semantic IDs;
- optional source units, canonical normalization metadata and qualifiers;
- provider/access/source/license metadata;
- read-only/destructive classification;
- tool and endpoint fingerprints;
- deterministic ranking evidence.

The result is a detached snapshot. Mutating a returned candidate does not mutate the registry.

## Retrieval은 execution authority가 아님

`retrieve()` is intentionally side-effect free.

```text
query
  -> SchemaRouter Top-K registered capabilities
  -> downstream LLM/agent selects among them
  -> SchemaRouter validation + policy
  -> trusted execution
  -> typed result
```

SchemaRouter does not expose a hidden pseudo-tool, invent a route, or allow retrieval confidence to
bypass local execution policy.

Plain `retrieve()` means the capability contract is registered. It does not imply a local invoker
is currently bound. `retrieve_executable()` adds that readiness requirement.

## 안정 제품 경계

0.11.0 keeps the existing product capabilities from 0.10.0:

- typed Tool / Endpoint / Parameter / Field registry;
- OpenAPI, MCP, OPTIMADE and Python ingestion;
- field-first planning and multi-provider field coverage;
- input/raw-output JSON Schema validation;
- binding/schema drift protection;
- read/write/destructive policy and approval gates;
- bounded retry, health and fallback;
- explicit field projection and trusted unit normalization;
- sync/async, batch, streaming, typed events and traces;
- SQLite persistence/inspection surfaces;
- optional LangChain, LangGraph, LlamaIndex, System One/Jev, Laya, Ollama and OpenTelemetry
  integration surfaces.

## 연구는 안정 library의 downstream으로 분리

The active 0.14 research asks whether compact typed retrieval preserves or improves downstream agent
utility relative to exposing the full tool catalog.

That research remains important, but it is no longer a prerequisite for publishing the usable
library. B1/B2 replication, answer-quality, adaptive shortlist depth, state-aware corrective
re-retrieval, larger held-out generalization and typed-representation ablations continue as separate
evidence tracks.

A research result blocks a stable package only when it exposes a reproducible product correctness,
security, policy, execution-authority, API-integrity, or packaging defect.

## 호환성

The new retrieval APIs are additive. Existing planning and execution APIs are not intentionally
changed by this release.

SchemaRouter is **Beta / pre-1.0**. A later 1.0 should represent an explicit long-term public
API compatibility commitment, not merely the completion of one research cycle.
