# SchemaRouter 0.16.0

SchemaRouter 0.16.0은 기존 typed capability·execution boundary 위에 **enterprise data onboarding과
권한관리**를 확장한 릴리스입니다.

Caller-owned 데이터 시스템을 더 폭넓게 등록할 수 있게 하되 SchemaRouter가 IAM 서버, DB proxy,
자율 orchestrator가 되지 않는 경계를 유지합니다.

## Identity-aware authorization

Host application이 검증한 `PrincipalContext`를 전달하면 role, department, team, trusted
attribute를 기준으로 deny-by-default RBAC/ABAC를 적용할 수 있습니다.

권한 검사는 모델에 capability를 보여 주기 전에 적용하고 실행 직전에 다시 검증합니다.
Data-scope rule은 visible field, trusted row/tenant filter, graph relationship 집합, 최대 traversal
depth까지 더 좁힐 수 있습니다.

인증, SSO/token 검증, identity directory, DB-native role은 계속 host가 소유합니다.

## 관계형 DB onboarding

Local SQLite connection과 caller-owned SQLAlchemy Engine을 schema introspection해 typed read-only
capability로 등록할 수 있습니다.

모델에 arbitrary SQL 실행 권한을 주지 않습니다. Introspect한 schema, bounded projection,
지원되는 exact-match parameter, parameterized execution만 노출합니다.

SQLAlchemy 경로는 dialect가 지원하는 관계형/warehouse 시스템을 같은 계약으로 연결하되,
credential, pool, live connection은 model-visible contract 밖에 유지합니다.

## Vector DB

Provider-neutral vector contract와 함께 다음 caller-owned native adapter를 제공합니다.

- Qdrant
- Milvus
- Pinecone
- Weaviate
- Chroma
- PostgreSQL/pgvector

Adapter는 collection/index schema를 탐색하거나 필요한 정보를 명시적으로 받고, vector
dimension을 검증하며 embedding/vector 생성은 trusted host code 안에 둡니다. Principal 기반
metadata filter도 vendor-safe query structure로 적용합니다.

## Graph / RDF

Graph contract에는 다음 caller-owned native adapter가 포함됩니다.

- Neo4j
- Amazon Neptune Database / Neptune Analytics
- ArangoDB
- FalkorDB
- SPARQL 1.1 endpoint

FalkorDB는 graph, label, relationship, property discovery와 `ro_query()` 기반 bounded read-only
traversal을 지원합니다. Release-gated compatibility는 실제 FalkorDB container와 공식 Python
client를 사용해 discovery와 traversal을 검증합니다.

Raw Cypher, AQL, Gremlin, SPARQL을 모델의 실행 권한으로 노출하지 않습니다.

## Document / search / key-value / time-series

Bounded record-store contract에 다음 caller-owned native adapter가 추가됩니다.

- MongoDB
- Elasticsearch / OpenSearch
- Amazon DynamoDB
- Azure Cosmos DB for NoSQL
- Couchbase
- ClickHouse
- InfluxDB 2.x / Flux

Vendor query language는 모델 출력이 아니라 trusted adapter 내부에 남습니다.

## Redis 경계

0.16에서는 일반 Redis record/vector/search를 first-class core database surface에 포함하지
않습니다. FalkorDB는 Redis 일반 기능과 별개로 graph contract를 통해 graph DB로 지원합니다.

Core는 schema discovery와 bounded execution 의미가 명확한 데이터 모델에 집중합니다.
Redis-specific 요구가 생기면 plugin 또는 adopter-owned adapter로 확장할 수 있습니다.

## Provider discovery 경계

알 수 없는 provider의 discovery는 proposal-first 방식입니다. Discovery가 inspectable candidate를
만들 수는 있지만 explicit approval 전에는 등록·실행 권한을 만들지 않습니다.

기존 known-provider 중심 onboarding도 그대로 유지됩니다.

## 호환성

기존 stable retrieval/execution facade는 유지됩니다. 0.16은 같은 capability contract 위에
onboarding, authorization, adapter surface를 추가합니다.

SchemaRouter는 계속 **Beta / pre-1.0**입니다. 특정 vendor가 core support 목록에 있다는 것은
bounded adapter와 contract가 있다는 뜻이며, 모든 hosted account/version/deployment topology가
live acceptance를 완료했다는 의미는 아닙니다.
