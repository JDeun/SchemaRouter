# SchemaRouter 0.13.0

stable core 위의 operational-completeness release입니다. OpenAPI/MCP/OPTIMADE/GraphQL/OData/OpenRPC/HTTP-JSON/Python/SDK/framework/plugin ingestion을 정리하고 nested record-preserving field contract, trusted local amendment, schema reinspect/watch/ETag lifecycle을 추가했습니다. 0.14 agent-utility research는 package usability와 독립적입니다.

## 호환성과 신뢰 경계

SchemaRouter는 pre-1.0 정책을 따릅니다. remote schema나 model output은 execution authority를 부여하지 않으며 credential, policy, approval, schema/fingerprint validation은 trusted local boundary에 남습니다. 해당 release의 세부 변경과 migration 정보는 repository `CHANGELOG.md` 및 versioning 문서를 함께 참고하세요.

## 설치

```bash
pip install "schemarouter==0.13.0"
```
