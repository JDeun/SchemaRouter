# SchemaRouter 0.13.0

SchemaRouter 0.13.0은 0.12.0에서 확립한 stable-core boundary 위의 **operational-completeness release**입니다.

Architecture를 다시 여는 release가 아닙니다. 동일 typed capability contract를 실제 protocol, SDK, transport, nested-result, schema-lifecycle surface에 연결할 때 나타나는 concrete product gap을 닫습니다.

## Universal capability ingestion

First-class ingestion surface:

- direct `ToolSpec` registration과 typed Python callable
- `add_bound_tool()`을 통한 explicit `ToolSpec` + trusted arbitrary SDK/client invoker
- OpenAPI/Swagger
- MCP Streamable HTTP, 신뢰된 stdio 하위 프로세스, 전송 방식에 종속되지 않는 바인딩 클라이언트 팩토리
- OPTIMADE
- native selection semantics를 가진 GraphQL introspection
- `$select`를 가진 OData CSDL
- OpenRPC / JSON-RPC
- declarative HTTP/JSON capability
- inbound LangChain/LlamaIndex tool
- explicit SourceAdapter plugin과 기존 grounded-document proposal/approval path

하나의 logical provider에 대한 access path는 서로 distinct합니다. Registry는 Python SDK, MCP server, OpenAPI endpoint, OPTIMADE service를 같은 transport로 가장하지 않고 provider/access identity를 기록합니다.

## Field contract가 실제 nested response에서도 유지됨

Structured adapter는 동일 field contract model에 맞춰집니다. Nested OpenAPI/MCP/OPTIMADE response, Python/plugin schema, record array가 declared hierarchy를 유지합니다.

Record array 같은 response는 **record by record**로 project됩니다. Matching child value를 unrelated list로 flatten하지 않습니다. Datatype, semantic ID, optional unit, normalization, qualifier, result path는 registered field contract에 붙어 있습니다.

Provider가 result contract를 생략하면 trusted local code가 imported capability를 amend할 수도 있습니다. 이 path는 의도적으로 좁습니다. Approved data contract를 declare/annotate할 수 있지만 imported execution identity를 조용히 rewrite하거나 remote mutation authority를 부여할 수 없습니다.

## Schema lifecycle의 operationalization

Remote metadata를 authority로 만들지 않고 schema drift를 처리할 수 있습니다.

```text
accepted ToolSpec
  -> reinspect provider
  -> exact fingerprint + conservative compatibility report
  -> identical: no write
  -> compatible: optional CAS apply + exact rebind
  -> breaking/security: pending review
```

Periodic watcher도 bounded concurrency로 동일 boundary를 실행합니다.

Safe single-document HTTP schema surface는 network optimization으로 `ETag` / `Last-Modified` validator를 사용할 수 있습니다. Validator가 없거나 충분하지 않으면 correctness는 full inspection/fingerprint comparison으로 돌아갑니다.

MCP stdio/custom transport는 HTTP URL을 만들어내지 않고 refresh할 수 있습니다. SchemaRouter는 current fingerprint-matched process-local trusted factory만 재사용합니다. Credential, subprocess config, socket, live transport state는 `ToolSpec` 또는 watcher snapshot에 serialize하지 않습니다. Missing/stale trusted binding은 fail closed입니다.

## Stable-core boundary 유지

0.13.0은 SchemaRouter를 autonomous agent framework로 바꾸지 않으며 retrieval/remote schema에 execution authority를 주지 않습니다.

Surrounding application/agent가 bounded registered candidate 중 선택합니다. SchemaRouter는 typed registry identity, argument/output validation, field projection, local policy, approval, binding readiness, execution을 계속 소유합니다.

0.11.0에서 도입하고 0.12.0에서 stable core로 freeze한 public bounded retrieval facade가 product boundary입니다.

- `retrieve` / `aretrieve`
- `retrieve_executable` / `aretrieve_executable`
- validated planning/invocation API와 기존 policy boundary

## Research remains separate

0.14 agent-utility research cycle은 독립적으로 계속됩니다. B1/B2 evidence, negative structural K3-vs-K5 gate, corrective re-retrieval, large held-out confirmation, final-answer quality, output-field projection experiment는 package release usability를 통제하지 않습니다.

0.13.0 준비를 위해 frozen 0.14 experimental corpus, ranking condition, promotion gate, evidence interpretation을 변경하지 않았습니다.

## Compatibility

0.12.0 대비 intentional breaking public API change가 없습니다. New ingestion, bound transport, field-contract, schema-watch path는 additive입니다.

SchemaRouter는 **Beta / pre-1.0**입니다. 0.12 stable-core architecture를 보존하면서 0.x minor release는 boundary 주변에 deliberately documented capability를 추가할 수 있습니다.

## Release integrity

Release commit은 publication 전에 protected CI matrix를 통과해야 합니다. Automated release workflow는 exact green `main` SHA에 `v0.13.0`을 만들고 wheel/sdist를 build/clean-install하며 provenance attestation과 SPDX SBOM을 생성하고 PyPI Trusted Publishing으로 publish한 뒤 public artifact와 integration extra를 정확히 검증합니다.
