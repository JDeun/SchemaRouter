# SchemaRouter 0.9.0

provider-neutral PairwiseDecisionBackend와 fresh operation-generalization evidence를 추가했습니다. frozen BGE one-shot은 overall 51.667%, supported-operation 25.781%, near-domain rejection 97.396%, OOD 100%, mean CPU latency 589.627 ms였고, trade-off 때문에 BGE를 default로 승격하지 않았습니다. consumed holdout은 이후 tuning에 재사용하지 않습니다.

## 호환성과 신뢰 경계

SchemaRouter는 pre-1.0 정책을 따릅니다. remote schema나 model output은 execution authority를 부여하지 않으며 credential, policy, approval, schema/fingerprint validation은 trusted local boundary에 남습니다. 해당 release의 세부 변경과 migration 정보는 repository `CHANGELOG.md` 및 versioning 문서를 함께 참고하세요.

## 설치

```bash
pip install "schemarouter==0.9.0"
```
