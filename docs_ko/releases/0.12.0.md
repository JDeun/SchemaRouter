# SchemaRouter 0.12.0

stable-core product closure release입니다. typed registry → bounded retrieval → agent/application → validated local-policy execution이라는 architecture/API boundary를 freeze했습니다. installed wheel/sdist consumer acceptance와 framework policy regression을 강화했고 research는 이 boundary 뒤의 독립 track으로 분리했습니다.

## 호환성과 신뢰 경계

SchemaRouter는 pre-1.0 정책을 따릅니다. remote schema나 model output은 execution authority를 부여하지 않으며 credential, policy, approval, schema/fingerprint validation은 trusted local boundary에 남습니다. 해당 release의 세부 변경과 migration 정보는 repository `CHANGELOG.md` 및 versioning 문서를 함께 참고하세요.

## 설치

```bash
pip install "schemarouter==0.12.0"
```
