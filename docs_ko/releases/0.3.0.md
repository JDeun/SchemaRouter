# SchemaRouter 0.3.0

SchemaRouter 0.3.0은 0.3 line의 첫 non-prerelease release입니다.

Validated 0.3.0a1 feature set을 intentional public API change 없이 승격하고 일반 PyPI 설치에서 `--pre`가 필요하지 않게 합니다. SchemaRouter는 pre-1.0이므로 이후 0.x minor release는 versioning policy에 따라 의도적인 compatibility change를 포함할 수 있습니다.

## 주요 변경사항

- deterministic fallback을 가진 provider-neutral bounded `DecisionBackend`
- `schemarouter[jev]` optional Jev/TypeSafe System One decision backend
- SchemaRouter execution authority를 유지하는 first-class LangChain/LlamaIndex bridge
- OpenAPI, MCP, OPTIMADE, Python callable, allowlisted third-party adapter path
- checked-in 144-case multilingual/adversarial decision-routing benchmark corpus
- machine-readable OpenAPI compatibility reporting
- authenticated MCP trusted-header와 injectable `MCPClientFactory`
- trusted sync/async per-call approval callback
- per-run logical-call, attempt, remote-attempt, elapsed-time, per-tool, cost-unit budget
- `schemarouter[otel]` optional privacy-preserving OpenTelemetry run/tool span
- strict package/type/coverage/integration/documentation/release validation

## Compatibility와 validation

Release gate:

- Python 3.10~3.14
- Windows + Python 3.14 smoke
- Pyright static typing
- 82% branch-coverage floor
- minimum runtime dependency version
- wheel/sdist build와 clean-install smoke
- strict MkDocs build
- LangChain, LlamaIndex, Jev, MCP, OpenTelemetry integration suite
- package metadata, license inclusion, quickstart, release artifact verification

Python 3.15는 별도 non-blocking forward-compatibility preview입니다. Public OpenAPI/OPTIMADE live smoke는 deterministic merge blocker가 아니라 external signal입니다.

## Security model

0.3.0은 alpha cycle의 fail-closed execution model을 유지합니다.

- unknown schema member와 bounded-decision option ID는 executable이 될 수 없음
- stale schema fingerprint/invoker binding 거부
- remote metadata/model output은 mutation/destructive authority를 부여할 수 없음
- credential은 planner/model state 밖에 유지
- retry는 기본적으로 read-only
- approval failure/budget exhaustion은 fail-closed
- OpenTelemetry export는 기본적으로 payload value/exception message 제외
- OpenAPI runtime response는 decoding 전에 bounded

## 0.3.0a1에서의 변경

0.3.0a1과 0.3.0 사이 intentional public API change는 없습니다. Non-prerelease release는 validated alpha surface 승격, repository enforcement/documentation deployment 마무리, `--pre` 없는 standard installation 제공이 핵심입니다.

Live provider benchmark evidence와 추가 open bounded-decision backend는 deterministic core release blocker가 아닌 후속 research track입니다.
