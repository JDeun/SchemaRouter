# SchemaRouter 0.3.0

0.3 alpha surface를 의도적 public API 변경 없이 첫 non-prerelease 0.3 release로 승격했습니다. 일반 설치에서 --pre가 필요 없어졌고 Python 3.10–3.14, Windows, typing/coverage, minimum dependencies, wheel/sdist, integrations, docs를 release gate로 검증했습니다.

## 호환성과 신뢰 경계

SchemaRouter는 pre-1.0 정책을 따릅니다. remote schema나 model output은 execution authority를 부여하지 않으며 credential, policy, approval, schema/fingerprint validation은 trusted local boundary에 남습니다. 해당 release의 세부 변경과 migration 정보는 repository `CHANGELOG.md` 및 versioning 문서를 함께 참고하세요.

## 설치

```bash
pip install "schemarouter==0.3.0"
```
