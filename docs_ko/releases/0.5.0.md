# SchemaRouter 0.5.0

runtime hardening release입니다. NonRetryableInvocationError, conservative HTTP retry classification, wall-clock budget-aware backoff, approval/hook budget accounting, OpenAPI parameter precedence·endpoint naming·request body/header·multi-2xx response fidelity를 강화했습니다.

## 호환성과 신뢰 경계

SchemaRouter는 pre-1.0 정책을 따릅니다. remote schema나 model output은 execution authority를 부여하지 않으며 credential, policy, approval, schema/fingerprint validation은 trusted local boundary에 남습니다. 해당 release의 세부 변경과 migration 정보는 repository `CHANGELOG.md` 및 versioning 문서를 함께 참고하세요.

## 설치

```bash
pip install "schemarouter==0.5.0"
```
