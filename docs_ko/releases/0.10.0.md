# SchemaRouter 0.10.0

consolidation release로 SchemaRouter를 agent/RAG와 registered API/tool 사이의 **typed capability retrieval and execution layer**로 명확히 정의했습니다. scientific datatype/unit/normalization/qualifier contract와 conservative cross-provider fallback을 정리하고 routing research 결과와 stable product boundary를 분리했습니다.

## 호환성과 신뢰 경계

SchemaRouter는 pre-1.0 정책을 따릅니다. remote schema나 model output은 execution authority를 부여하지 않으며 credential, policy, approval, schema/fingerprint validation은 trusted local boundary에 남습니다. 해당 release의 세부 변경과 migration 정보는 repository `CHANGELOG.md` 및 versioning 문서를 함께 참고하세요.

## 설치

```bash
pip install "schemarouter==0.10.0"
```
