# SchemaRouter 0.3.0a1

SchemaRouter 0.3.0a1은 두 번째 public alpha이며 0.2.0a1 이후 개발된 expanded production-oriented schema execution boundary의 첫 release입니다.

## Highlights

- deterministic fallback을 가진 provider-neutral bounded `DecisionBackend` contract
- `schemarouter[jev]`를 통한 optional Jev / TypeSafe System One decision backend
- SchemaRouter execution authority를 보존하는 first-class LangChain/LlamaIndex bridge
- 저장소에 포함된 다국어·적대적 의사결정 라우팅 벤치마크 코퍼스 144개 사례
- machine-readable OpenAPI compatibility reporting
- authenticated MCP trusted-header support와 injectable `MCPClientFactory`
- 신뢰된 동기·비동기 호출별 승인 콜백
- logical call, attempt, remote attempt, elapsed time, per-tool quota, application-defined cost unit을 위한 per-run execution budget
- `schemarouter[otel]`을 통한 optional privacy-preserving OpenTelemetry run/tool span
- `schemarouter.adapters` entry-point group을 통한 explicit allowlisted third-party adapter plugin

## Security와 execution controls

0.3.0a1은 execution authority를 local에 두고 fail-closed합니다.

- unknown decision option ID는 confidence handling 전에 fail closed
- provider failure는 policy를 우회하지 않고 deterministic fallback 가능
- MCP credential은 trusted transport configuration에 유지되며 MCP URL에 embedded credential은 거부
- protocol-controlled MCP header는 trusted-header configuration으로 override 불가
- approval-required call은 approval 누락/거절/error 시 fail closed
- retry는 invocation 전에 attempt/remote-attempt/cost budget 소비
- wall-clock budget은 async tool execution 중단 가능
- adapter plugin discovery는 installed plugin code를 import하지 않음
- OpenTelemetry export는 argument value, result payload, RunConfig metadata, tag, exception message를 생략
- OpenAPI runtime response는 decode 전에 bounded 상태 유지

## Benchmarking

Repository는 normal routing, near-duplicate endpoint, Korean/English query, long-tail phrasing, adversarial/OOD request를 포함한 144 fixed case의 `benchmarks/decision-routing-v1.json`을 포함합니다.

Harness 보고:

- final routing accuracy
- invalid-plan rate
- bounded-backend abstention recall
- deterministic fallback count
- category-level accuracy
- mean/p50/p95 latency
- token usage와 optional dated cost estimate
- row-level JSON/CSV output

Live provider measurement는 credential, model revision, provider availability, pricing이 external variable이므로 deterministic CI와 분리합니다.

## Installation

Exact release:

```bash
pip install "schemarouter==0.3.0a1"
```

Latest prerelease:

```bash
pip install --pre schemarouter
```

Optional integrations:

```bash
pip install --pre "schemarouter[mcp]"
pip install --pre "schemarouter[langchain]"
pip install --pre "schemarouter[llamaindex]"
pip install --pre "schemarouter[jev]"
pip install --pre "schemarouter[otel]"
```

## Alpha status

Pre-1.0 alpha입니다. Core trust model과 public contract는 regression-tested지만 0.x minor/prerelease development는 changelog/versioning policy에 문서화된 deliberate API change를 여전히 도입할 수 있습니다.

Complete compatibility/security policy는 `CHANGELOG.md`, `docs/versioning.md`, `SECURITY.md`, `docs/release-checklist.md`를 참고하십시오.
