# SchemaRouter 0.3.0a1

두 번째 public alpha로 bounded DecisionBackend, Jev/System One, LangChain/LlamaIndex bridge, 144-case multilingual/adversarial benchmark, OpenAPI compatibility report, authenticated MCP, approval callback, execution budget, OpenTelemetry, allowlisted adapter plugin을 추가했습니다. execution authority와 credential은 계속 local/fail-closed로 유지합니다.

## 호환성과 신뢰 경계

SchemaRouter는 pre-1.0 정책을 따릅니다. remote schema나 model output은 execution authority를 부여하지 않으며 credential, policy, approval, schema/fingerprint validation은 trusted local boundary에 남습니다. 해당 release의 세부 변경과 migration 정보는 repository `CHANGELOG.md` 및 versioning 문서를 함께 참고하세요.

## 설치

```bash
pip install "schemarouter==0.3.0a1"
```
