# SchemaRouter 0.6.0

bounded local/model-assisted decision, operational inspection/dashboard, OpenAPI fidelity를 확장했습니다. Laya local decision backend와 CPU/CUDA/MPS 선택, live SchemaRouter.inspect/CLI inspection, provider-neutral cloud client reuse를 추가하면서 model은 finite authorized IDs 밖의 authority를 갖지 않게 유지했습니다.

## 호환성과 신뢰 경계

SchemaRouter는 pre-1.0 정책을 따릅니다. remote schema나 model output은 execution authority를 부여하지 않으며 credential, policy, approval, schema/fingerprint validation은 trusted local boundary에 남습니다. 해당 release의 세부 변경과 migration 정보는 repository `CHANGELOG.md` 및 versioning 문서를 함께 참고하세요.

## 설치

```bash
pip install "schemarouter==0.6.0"
```
