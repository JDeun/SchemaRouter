# SchemaRouter 0.8.0

open-set routing과 scientific capability contract를 더 정교하게 만든 release입니다. semantic recall, unsupported/no-route 처리, operation-level 구분과 evidence/field contract를 강화했으며 benchmark 결과는 product default와 분리해 기록했습니다.

## 호환성과 신뢰 경계

SchemaRouter는 pre-1.0 정책을 따릅니다. remote schema나 model output은 execution authority를 부여하지 않으며 credential, policy, approval, schema/fingerprint validation은 trusted local boundary에 남습니다. 해당 release의 세부 변경과 migration 정보는 repository `CHANGELOG.md` 및 versioning 문서를 함께 참고하세요.

## 설치

```bash
pip install "schemarouter==0.8.0"
```
