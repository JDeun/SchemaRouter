# SchemaRouter 0.2.0a1

최초 packaged alpha입니다. typed tool/endpoint/parameter/field/plan/result contract, fail-closed schema·binding drift 검사, OpenAPI/OPTIMADE/MCP/Python callable, LangChain integration, grounded documentation proposal, sync/async/batch/stream/event/retry를 공개했습니다. Python 3.10–3.12, wheel/sdist, strict docs, MCP/LangChain 및 public OpenAPI·COD OPTIMADE smoke로 검증했습니다.

## 호환성과 신뢰 경계

SchemaRouter는 pre-1.0 정책을 따릅니다. remote schema나 model output은 execution authority를 부여하지 않으며 credential, policy, approval, schema/fingerprint validation은 trusted local boundary에 남습니다. 해당 release의 세부 변경과 migration 정보는 repository `CHANGELOG.md` 및 versioning 문서를 함께 참고하세요.

## 설치

```bash
pip install "schemarouter==0.2.0a1"
```
