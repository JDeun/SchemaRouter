# SchemaRouter 0.2.0a1

SchemaRouter 0.2.0a1은 schema-aware planning 및 execution framework의 첫 공개 packaged alpha입니다.

## 주요 변경

- canonical typed contracts for tools, endpoints, parameters, fields, plans, and results;
- fail-closed execution with schema/binding drift detection and raw output validation;
- structured-source adapter ecosystem through `AdapterRegistry` / `SourceAdapter`;
- OpenAPI 3.x ingestion with guarded origins and credential separation;
- first-class OPTIMADE discovery and execution with protocol-native `response_fields`;
- MCP Streamable HTTP discovery/execution using the official SDK;
- typed Python callable registration;
- optional LangChain `StructuredTool` integration;
- human-readable API documentation proposals with quote grounding and explicit approval;
- async/sync invoke, batch, streaming, events, retries, and bounded concurrency;
- MIT licensing, MkDocs documentation, package verification, and production branding.

## 호환성 검증

Release는 다음 항목을 대상으로 검증했습니다:

- Python 3.10, 3.11, and 3.12;
- wheel/sdist build and clean-wheel installation;
- strict MkDocs build;
- real MCP Streamable HTTP integration;
- LangChain integration;
- public OpenAPI live smoke;
- public COD OPTIMADE live smoke.

## Pre-release 상태

이 버전은 alpha release입니다. Public API는 문서화되고 regression test를 거쳤지만 project는 아직 pre-1.0이며 이후 minor release에서 breaking change가 도입될 수 있습니다.
