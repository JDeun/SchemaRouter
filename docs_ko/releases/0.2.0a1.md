# SchemaRouter 0.2.0a1

SchemaRouter 0.2.0a1은 schema-aware planning/execution framework의 최초 packaged alpha release입니다.

## 주요 기능

- tool, endpoint, parameter, field, plan, result의 canonical typed contract
- schema/binding drift detection과 raw output validation을 포함한 fail-closed execution
- `AdapterRegistry` / `SourceAdapter` 기반 structured-source adapter ecosystem
- guarded origin과 credential separation을 적용한 OpenAPI 3.x ingestion
- protocol-native `response_fields`를 포함한 first-class OPTIMADE discovery/execution
- official SDK 기반 MCP Streamable HTTP discovery/execution
- typed Python callable registration
- optional LangChain `StructuredTool` integration
- quote grounding과 explicit approval을 포함한 human-readable API documentation proposal
- async/sync invoke, batch, streaming, event, retry, bounded concurrency
- MIT license, MkDocs documentation, package verification, production branding

## 호환성 검증

Release는 다음으로 검증했습니다.

- Python 3.10, 3.11, 3.12
- wheel/sdist build와 clean-wheel installation
- strict MkDocs build
- 실제 MCP Streamable HTTP integration
- LangChain integration
- public OpenAPI live smoke
- public COD OPTIMADE live smoke

## Pre-release 상태

Alpha release입니다. Public API는 문서화되고 regression test가 있지만 project는 pre-1.0이며 이후 minor release에서 breaking change가 있을 수 있습니다.
