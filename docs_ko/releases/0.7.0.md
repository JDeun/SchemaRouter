# SchemaRouter 0.7.0

SchemaRouter 0.7.0은 이전 release에서 도입한 field-first execution boundary를 강화합니다. General agent runtime으로 확장하지 않고 provider/access resilience, typed scientific result contract, operation-scoped policy, bounded observability, release/supply-chain verification에 집중합니다.

## Highlights

### Field-first provider와 access routing

0.7은 transport 선택 전에 logical data need를 더 명시적으로 만듭니다.

- explicit provider/access identity와 precompiled read-only fallback route
- optional cross-provider fallback 전에 same-provider alternative 선호
- fallback을 자체 parameter/field contract에 대해 독립 compile
- OpenAPI/OPTIMADE용 trusted server-side field projection contract
- raw-response validation 후 final local projection 유지
- finite access-path cooldown + recovered read-only route를 permanent blacklist 없이 reopen하는 trusted background health probe
- execution-ready planning surface로 execution-facing planning을 binding-aware하게 함

Fallback은 bounded/fail-closed입니다. Schema, policy, approval, mutation, deterministic 4xx, stale-contract failure는 generic availability failure로 취급하지 않습니다.

### Typed scientific fields, units, exact qualifiers

같은 이름이지만 교환 불가능한 value를 구별할 수 있도록 scientific field contract metadata를 확장합니다.

- selected result field의 explicit JSON value-shape contract
- optional exact source-unit metadata
- declared canonical unit으로 affine `UnitNormalizationSpec` conversion
- numeric-array normalization
- downstream용 compact `ToolResult.field_contracts`
- temperature, phase, orientation, pressure, measurement method 같은 fixed context용 exact trusted `FieldSpec.qualifiers`

Qualifier는 schema fingerprint, inspection, schema-diff, cross-provider fallback compatibility, bounded field selection에 참여합니다. Query에 qualifier가 명시적으로 보이면 deterministic routing이 otherwise-equivalent field 구별에 사용할 수 있습니다.

SchemaRouter는 scientific equivalence 추론, qualifier value conversion, ontology term normalization, unstated measurement context synthesis를 하지 않습니다.

### Trusted parameter aliases

`ParameterSpec.aliases`는 model-authored remapping 없이 동일 logical argument를 provider-specific local parameter name에 bind합니다.

보수적 rule:

- exact parameter name 우선
- alias는 trusted local schema declaration
- ambiguous alias는 fail closed
- candidate indexing이 alias 인식
- fallback call은 각 access contract에 독립 compile

### Policy, schema drift, explainability

- ordered operation-scoped `PolicyRule`: `allow`, `deny`, `require_approval`
- additive/breaking/security-review classification을 가진 conservative endpoint/tool schema-diff
- diff가 informational이어도 exact schema/tool fingerprint가 execution authority
- deterministic score component, field-selection reason, ignored undeclared argument, bounded decision-selection source를 위한 structured `PlanExplanation`
- preflight validation/shared budget/bounded concurrency/completion-order streaming의 explicit `parallel_read_only` fan-out

Explanation은 locally observable routing signal만 노출하며 model chain-of-thought를 노출하지 않습니다.

## Compatibility

0.7.0은 0.6.0의 public API를 제거하지 않습니다.

Automatic fallback 일부는 의도적으로 더 엄격합니다. Datatype/unit/canonical-unit/exact-qualifier compatibility를 증명할 수 없으면 추측하지 않고 alternative route를 reject합니다. Fail-closed contract의 correctness/security 강화입니다.

Pre-1.0이므로 이후 0.x minor는 documented compatibility change를 도입할 수 있습니다.
