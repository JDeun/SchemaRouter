# SchemaRouter 0.7.0

schema-aware execution과 routing 연구 기반을 확장한 release입니다. decision surface와 benchmark/reproducibility를 강화하고 production path와 experimental model-assisted routing을 분리했습니다. 새 기능도 local policy/fingerprint/schema validation을 우회하지 않습니다.

## 호환성과 신뢰 경계

SchemaRouter는 pre-1.0 정책을 따릅니다. remote schema나 model output은 execution authority를 부여하지 않으며 credential, policy, approval, schema/fingerprint validation은 trusted local boundary에 남습니다. 해당 release의 세부 변경과 migration 정보는 repository `CHANGELOG.md` 및 versioning 문서를 함께 참고하세요.

## 설치

```bash
pip install "schemarouter==0.7.0"
```
