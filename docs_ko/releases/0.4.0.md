# SchemaRouter 0.4.0

operational runtime을 확장했습니다. transactional SQLiteRegistry, append-only SQLiteRunTraceStore, exact-recall candidate index, bounded field selection, nested projection, evidence-sufficiency gate, EmbeddingDecisionBackend/Ollama, native LangGraph, bounded same-origin OpenAPI external ref, trusted execution hook이 추가되었습니다.

## 호환성과 신뢰 경계

SchemaRouter는 pre-1.0 정책을 따릅니다. remote schema나 model output은 execution authority를 부여하지 않으며 credential, policy, approval, schema/fingerprint validation은 trusted local boundary에 남습니다. 해당 release의 세부 변경과 migration 정보는 repository `CHANGELOG.md` 및 versioning 문서를 함께 참고하세요.

## 설치

```bash
pip install "schemarouter==0.4.0"
```
