# CodeGraph 방식의 선택적 G5 컨텍스트: 실행 가능한 E1 설계

**날짜:** 2026-10-23

**상태:** 대화에서 구현 방향 승인; 상세 설계서는 구현 계획 작성 전에 유지관리자 검토 필요.

**추적:** [#1711](https://github.com/JDeun/SchemaRouter/issues/1711), M5.

**선행 작업:** [G5 통합 PR #1714](https://github.com/JDeun/SchemaRouter/pull/1714), [실행되지 않는 E0 PR #1715](https://github.com/JDeun/SchemaRouter/pull/1715).
**연구 기준:** [CodeGraph E0 실험](../../research/codegraph-surgical-context-e0.md).

## 1. 목적과 결정

사용자는 직렬화 단위의 미세조정보다 **완결된 기능과 실제 작업·비용 증거**를 원합니다. 승인된 방향은 기존의 출처 검증된 G5 **참조 전용** 컨텍스트를 외부 연구용 에이전트에서 활용할 수 있도록 별도의 권한 검증을 거치는 원본 도구 스키마의 지연 공개 단계를 추가하는 것입니다. 목적은 초기 컨텍스트 감소분이 추가 스키마 요청 및 모델 호출 비용을 상쇄하는지 확인하는 것이며, **새로운 실행 권한을 생성하는 것은 아닙니다**.

E0에서 확인된 수치는 권한 검증된 합성 2개 경로의 UTF-8 JSON 크기 1,825바이트 대비 1,028바이트, 즉 43.67% 감소뿐입니다. 실제 토큰, 작업 성공률 또는 금전적 비용을 뜻하지 않습니다. 동결된 #432의 작업 성공률 FULL 49.62%와 SR-5 29.19%로 인해 기본값 승격도 여전히 금지됩니다. 독립적인 제공자·작업 작성자 분리 E2는 [#1346](https://github.com/JDeun/SchemaRouter/issues/1346)에서 막혀 있으며, [#1356](https://github.com/JDeun/SchemaRouter/pull/1356)의 릴리스 중단 조건도 유지됩니다.

### 검토한 대안

1. **채택 — 기존 E1 연구 실행기에서 출처 재검증 기반 지연 스키마 공개:** 모델에 검증된 경로 참조와 고정된 최소 스키마 요청 도구를 먼저 제공합니다. 신뢰하는 호스트가 원본의 권한을 다시 검증한 뒤 요청된 스키마만 공개하고 기존 실행기를 통해 실제 도구를 호출합니다. 추가 왕복 호출까지 포함한 실험이 가능합니다.
2. **참조 프롬프트와 기존 전체 도구 목록을 동시에 제공:** 연결은 쉽지만 스키마 중복 노출로 컨텍스트 절감 가설을 검증할 수 없어 주 실험으로 채택하지 않습니다.
3. **토크나이저만 적용:** 별도 E0 통제로는 유효하지만 실행 가능한 에이전트 작업 결과가 없어 마일스톤의 주된 진척 증거로는 부족합니다.

새 AST CodeGraph 인덱스, 그래프 데이터베이스, 별도 그래프 순위 모델, 원본 제공자 어댑터, 범용 에이전트 실행기 또는 기본 공개 API 변경은 필요하지 않습니다.

## 2. 구성요소와 책임 경계

| 구성요소 | 기존 경계 | E1 변경 |
| --- | --- | --- |
| 출처·그래프 선택 | `retrieve_authorized_concept_graph`, `NativeSchemaGraphIndex`, `NativeConceptCatalog` | 원본 경로 ID, 형식이 검증된 생산자→소비자 바인딩, 고정 `k=5`, 출처 지문, 완전한 경로 판정을 재사용하며 관계를 추측하지 않음 |
| 주체별 스키마 | `capture_authorized_agent_tool_surface`, 검증된 `tool_definitions` | 선택된 경로만 받아 현재 실제로 볼 수 있는 원본 스키마를 반환하는 **연구 전용** 실체화 서비스 추가 |
| 권한 연속성 | 레지스트리·출처 증거, 정책 내용 영수증, 주체 정보 스냅샷 | 선택, 실체화, 모델 응답 처리, 실행마다 검사하고 변경 시 공개 결과를 폐기 |
| 원본 도구 실행 | `execute_scoped_host_call`, 기존 읽기 전용 어댑터 | 기존 인수·권한·출력 투영 검사 재사용; 스키마 공개 자체로 실행 권한 없음 |
| 모델·측정 | 고정된 로컬 Qwen, 원본 작업 정답 검사기 | 네 번째 실험 조건 추가, 실제 토큰과 호스트의 스키마 요청 비용·최종 작업 결과 보존 |

**신뢰 원칙:** 그래프 경로 ID, 모델이 제출한 경로 ID, 저장된 참조, 스키마 공개 성공 중 어떤 것도 **실행 허가가 아닙니다**. 비밀 정책, 원시 출처 메타데이터, 인증정보, 숨겨진 필드, 권한 없는 경로 수, 비공개 인수는 모델이나 저장된 실험 결과에 공개하지 않습니다. 스키마 요청 도구는 권한이 확인된 경로 참조와 최소 작업 설명만 다루며 전체 레지스트리를 열거할 수 없습니다.

## 3. E1 실행 프로토콜

1. 작업 시작 시 원본 레지스트리·인덱스 지문, 검토된 개념 사전, 명시적 `PrincipalContext`, 정책 내용 해시, 원본 질의를 고정합니다. 호스트는 `k=5` 기준으로 완전한 권한 검증 G5 경로를 선택합니다. `complete` 이외의 결과는 **원본 호출 없이 거절**합니다. 경로를 K에 맞추려고 자르거나 K를 키우지 않습니다.
2. **FULL**은 주체가 접근할 수 있는 모든 원본 정의, **lexical SR-5**는 기존 상위 5개 원본 정의, **typed G5**는 완전한 G5 경로의 원본 정의를 제공합니다. **surgical G5**는 동일하게 검증된 경로와 원본 출력 필드명·타입 바인딩·출처 버전 증거 및 작은 고정 호스트 도구 `request_scoped_source_schema`만 제공합니다. 처음에는 **실행 가능한 원본 도구를 하나도 공개하지 않습니다**.
3. 모델은 **명시적으로 선택된 한 개 이상의 경로 ID**에 대해서만 스키마 실체화를 요청할 수 있습니다. 와일드카드, 전체 탐색, 권한 거절 경로, 중복·초과 K·미선택 경로는 거절합니다. 호스트는 각 요청마다 최신 주체별 원본 뷰를 다시 확보하고 선택 증거, 완전한 바인딩, 경로·도구·엔드포인트 지문, 데이터 가시성, 정책 내용, 주체 정보를 검사합니다. 어느 하나라도 바뀌면 원본 호출 없이 작업을 중단하며, 정상일 때만 해당 부분집합의 실제 원본 도구 정의를 생성합니다.
4. 모델은 실체화가 완료된 원본 경로만 선택할 수 있습니다. 기존 호스트 호출기는 다시 권한·인수·출처를 검사한 후 읽기 전용 작업을 수행합니다. **스키마 요청 도구는 제공자를 호출하지 않습니다**. 스키마 요청은 별도 에이전트 턴으로 기록하고 추가 토큰을 측정합니다. 변경되지 않은 권한 증거 범위의 캐시만 허용하며, 캐시가 권한 재검증이나 측정된 컨텍스트 비용을 생략하게 만들지 않습니다.
5. 여러 작업이 이어지는 경로에서는 검증된 생산자의 **공개 가능한** 관측치와 완전한 출력→입력 바인딩만 소비자에게 전달합니다. 다른 사용자의 관측치나 정답 데이터로 값을 만들 수 없으며, 실제로 확인되지 않은 필수 인수를 사용한 소비자 호출은 거절합니다.
6. 기존 원본 기반 최종 정답 검사기로 결과를 평가합니다. 각 조건은 동일 질의, 제공자, 허용된 출처 계약, 모델 ID·리비전, 생성 설정, K5, 주체 및 시도 예산을 사용합니다. 모델 대신 경로를 실행하거나, 성공을 위한 숨겨진 프롬프트 보정·재시도를 추가하지 않습니다. 실시간 편향을 줄이기 위해 조건 실행 순서를 교차합니다.

이 기능은 **연구 전용 명시적 옵션**입니다. 안정화된 `SchemaRouter` API와 기본 에이전트 도구 목록은 변경하지 않습니다. 향후 제품 적용에는 별도의 위협 검토와 공개 API 설계가 필요합니다.

## 4. 실험 집단과 출처 검증

**집단 A — 실제 원본 2회 호출의 정확성:** #1714에서 사용한 비상업 연구용 원본 Open-Meteo의 위치 검색→날씨 조회 EN/KO/JA와 고정 Qwen 정답 검증을 재사용합니다. 등록된 원본 경로가 **2개뿐**이므로 실체화·권한·모델의 순차 호출·정답 일치 여부를 검사할 수 있지만 **큰 도구 목록의 비용 이점은 입증할 수 없습니다**. Open-Meteo 무료 비상업 이용 조건을 지키며 상업용 호스트는 자체 제공자 계약을 확보해야 합니다. 인증정보는 모델에 노출하지 않습니다.

**집단 B — 도구 목록 크기 통제:** 원본 출처 형식으로 등록하고 소유자가 검토한 읽기 전용·결정적 다중 경로 테스트 환경(최소 10개 경로)을 마련합니다. 형식 있는 필드 계약, 실제로 실행되는 호스트 콜백, 정해진 출력값을 사용하며 고정된 실제 모델이 호출을 수행합니다. 이를 **E1_LOCAL_SOURCE_CONTROL**로 명시하고 제3자 실제 API나 독립 E2 성과로 소개하지 않습니다. 지원되는 EN/KO/JA와 거절·부적합·K 초과 사례의 작업과 입력을 사전에 고정하고 검토합니다. 외부 제공자 관측치를 꾸며내지 않습니다.

두 집단은 분리 보고하며 제공자 가용 시간이 다른 결과를 인과적으로 합산하지 않습니다. 어떤 조건을 유리하게 만들기 위해 K, 숨은 문맥, 시도 횟수 또는 프롬프트 예산을 늘리지 않습니다. 출처 변경·원본 연결 실패는 `INCOMPARABLE_SOURCE_DRIFT` / `INCOMPARABLE_SOURCE_FAILURE` 및 **null 성공률**로 기록합니다. 원본이 정상인 상태에서 모델이 잘못 호출하거나 너무 일찍 답한 경우는 실제 작업 실패입니다. 모델 런타임이 없으면 `BLOCKED_MODEL_RUNTIME`으로 남기고 호출이나 0점 결과를 만들지 않습니다.

## 5. 측정 및 재현

조건·언어·작업별로 안전하게 정제한 출처 리비전·지문, 모델 ID·리비전, 선택 경로 동등성, 권한·거절 판정, 엄격한 작업 정답, 모델 턴, **스키마 요청 횟수**, 원본 도구 호출, 제공자 HTTP 시도와 검증된 응답, 모델 입력·도구 스키마·모델 출력·전체 처리 토큰, 측정된 생성 지연과 CPU·전체 경과시간, 신뢰 가능한 실패 단계 코드를 기록합니다.

실제 토큰 수는 **모든 턴**의 고정된 모델 생성 결과에서 가져옵니다. 스키마 요청 도구 정의, 실체화 응답, 뒤늦게 공개된 원본 스키마까지 포함합니다. 측정값이 없으면 0이 아닌 `null`로 보존합니다. JSON 바이트와 토크나이저 토큰을 구분합니다. 유효한 단가와 실제 비교 가능한 사용량이 없다면 금전적 절감률을 주장하지 않습니다. 초기 문맥이 줄더라도 호스트 도구 호출이 늘어난 사실을 숨기지 않습니다.

변경할 수 없는 정제된 실행 결과와 영문·국문 버전 관리 연구 기록을 남깁니다. 코드·출처·모델 리비전, 집단별 한계, Actions 실행 ID, 명령어, 실패 사례를 포함합니다. 원시 제공자 응답, 개인 인수, 비공개 정책, 인증정보, 비밀 토큰이 포함된 URL, 모델의 비공개 문맥은 저장하지 않습니다. 기존 E0와 #432 증거는 수정하지 않습니다.

## 6. 완료 조건과 출시 제약

1. **보안·기능:** 실패하는 테스트를 먼저 작성합니다. 출처 변경, 정책 내용 변경, 주체 교체, 제자리 데이터 권한 축소, 숨겨진 생산자 바인딩, 미선택 경로, 거절·부적합·K 초과가 스키마 공개나 제공자 호출 전에 차단됨을 입증합니다. 정상적인 2단계 경로는 실제 등록 콜백·기존 호출기를 통과하며 원본 정답과 일치해야 합니다.
2. **에이전트:** 실제 고정 모델로 네 번째 surgical 조건을 FULL·lexical SR-5·typed G5와 비교합니다. 모델이나 원격 출처 부재는 구체적인 비교 불가 기록으로 남깁니다. 합성 테스트 성공을 제공자 기반 성공으로 바꾸어 말하지 않습니다.
3. **비용:** 최초 직렬화 크기가 아닌 누적 실제 모델 토큰, 모델·도구 턴, 제공자 호출, 지연시간을 측정합니다. 비용이나 정확도가 나빠지는 결과도 유효합니다. 목표 수치를 맞추기 위한 미세조정은 하지 않습니다.
4. **호환성:** 명시적 연구 옵션만 사용하고 기본값, 필수 의존성, 경로 K, 출처 계약, 일반적인 LLM 실행 권한이나 상업적 이용 권한을 확장하지 않습니다. 기존 공개 API·보안 테스트를 유지합니다.
5. **출시:** PR 검토 전 전체 GitHub Actions와 한국어·문서 검증을 통과해야 하며 병합은 별도로 승인받습니다. #1711 M5는 E1 결론까지 열린 상태, #1346 E2는 독립 차단 상태, #1356 릴리스는 보류 상태입니다.

## 7. 보류 결정과 주요 위험

- **지연 실체화 비용이 초기 문맥 절약을 초과할 수 있습니다.** 특히 Open-Meteo의 2개 경로에서는 유력한 가설이며 이를 결과로 있는 그대로 보고합니다.
- 일반적인 스키마 요청이 경로 열거 통로가 될 수 있습니다. 긍정적으로 선택되고 주체에게 보이는 ID만 허용하며 거절·부재·만료·미선택 요청에는 동일한 정제된 거절을 제공합니다.
- 그래프 선택과 호스트 출처 뷰 조회는 서로 다른 읽기 작업입니다. E0의 지속적인 권한·출처 일치 검사를 조회와 실체화 전체 및 모든 원본 호출 직전까지 유지합니다.
- Open-Meteo 연결 타임아웃 때문에 과거 9개 실행 사례의 비교가 무효화되었습니다. 기존 통신 오류 분류를 유지하고 제공자 오류를 모델 오류라고 주장하거나 성공할 때까지 재시도하지 않습니다.
- 10개 경로의 합성 제공자는 로컬 프로토콜과 모델의 상호작용만 검증합니다. 실제 외부 제공자 적용과 독립 E2 품질의 증거가 아닙니다.

**2026-10-23 승인한 방향:** *참조 → 재검증된 스키마 요청 → 기존 권한 검증 실행 → 네 조건 E1*이며, 실제 2개 경로의 정확성 검사와 큰 도구 목록의 비용 검증을 분리합니다. 이 설계서를 검토하고 구현 계획을 승인하기 전에는 설계 승인만으로 구현이 허가된 것으로 간주하지 않습니다.
