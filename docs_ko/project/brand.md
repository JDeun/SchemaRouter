## Mark

mark는 schema/structure/typed contract를 뜻하는 **중괄호**와 tool/endpoint/field selection이 하나의 validated execution boundary를 통과한다는 **중앙 routing hub**를 결합합니다. teal 중심은 routing decision을, graphite/neutral geometry는 일반적인 AI branding보다 developer infrastructure에 가까운 시각 언어를 나타냅니다.

## Palette

| Token | Hex | 용도 |
| --- | --- | --- |
| Graphite | `#1F2937` | 밝은 배경의 기본 구조 |
| Near black | `#111827` | Wordmark / deep neutral |
| Teal | `#14B8A6` | 기본 accent |
| Bright teal | `#2DD4BF` | dark-mode accent |
| Light neutral | `#E5E7EB` | 어두운 배경의 구조 |
| Off white | `#F8FAFC` | 밝은 detail |

mark는 favicon/avatar/compact navigation/square surface에, lockup은 README/docs landing/package/project/presentation에 사용합니다. compact mark 주변에는 최소 central-node radius만큼 여백을 둡니다.

mark를 늘이거나 회전하지 말고 outer node를 개별 recolor하거나 glow/shadow/bevel/3D/rainbow gradient를 추가하지 않습니다. SVG asset이 있으면 generated concept image를 production master로 사용하지 않습니다.

GitHub social preview는 repository file을 자동 사용하지 않으므로 social-preview SVG를 1280×640 PNG로 export한 뒤 repository settings에서 설정합니다.
