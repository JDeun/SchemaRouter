# 브랜드

SchemaRouter는 **중괄호 + 라우팅 허브(brace + routing hub)** 정체성을 사용합니다.

## 마크

마크는 두 가지 개념을 결합합니다.

- **중괄호(curly braces)**: 스키마, 구조, 타입이 지정된 계약을 나타냅니다.
- **중앙 라우팅 허브**: 하나의 검증된 실행 경계를 통해 도구, 엔드포인트, 필드를 선택하는 과정을 나타냅니다.

청록색 중심점은 라우팅 결정을 뜻합니다. 그래파이트/중립 계열의 기하학적 형태를 사용해 일반적인 AI 브랜딩보다 개발자 인프라에 가까운 시각 언어를 유지합니다.

README, 문서 랜딩 페이지, 패키지/프로젝트 페이지, 프레젠테이션에는 **로고 조합(lockup)**을 사용합니다.

GitHub 저장소 소셜 이미지의 원본 아트워크에는 **소셜 미리보기**를 사용합니다.

## 여백 규칙

컴팩트 마크 주변에는 최소한 중앙 노드 반지름 하나만큼의 빈 공간을 유지합니다. 중괄호 주변에 배지나 텍스트를 빽빽하게 배치하지 않습니다.

## 금지 사항

- 마크를 늘이거나 회전하지 않습니다.
- 바깥쪽 노드의 색상을 개별적으로 바꾸지 않습니다.
- 광택, 그림자, 베벨 또는 3D 효과를 추가하지 않습니다.
- 청록색 허브를 무지개/AI 그라디언트로 바꾸지 않습니다.
- 어두운 배경에 다크 로고 조합을, 밝은 배경에 라이트 로고 조합을 사용하지 않습니다.
- SVG 에셋이 제공되는 경우 생성형 콘셉트 이미지를 프로덕션 원본으로 사용하지 않습니다.

## GitHub 소셜 미리보기

GitHub는 저장소 파일을 소셜 미리보기 이미지로 자동 사용하지 않습니다.
`schemarouter-social-preview.svg`를 1280×640 PNG로 내보낸 다음, 브랜딩 브랜치가 병합된 뒤 저장소의 소셜 미리보기 설정에서 지정합니다.
