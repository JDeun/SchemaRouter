# Independent EN/KO semantic review protocol (#1202)

**Status: open until a genuinely independent reviewer has completed all 147 pairs.**
This file specifies an acceptance process; it is **not** a certificate or sign-off.

## Scope and reviewer separation

1. Pin the exact Git commit. Compare every English page under docs/ with its
   matching Korean page under docs_ko/. Run
   python -m scripts.audit_translation_review_units --json-out translation-review-units.json
   to inventory SHA-256-hashed headings, paragraphs, list items and table lines.
2. Use a bilingual reviewer who did not author the translations being certified.
   Record real reviewer identity, date and basis of independence. Verify that
   identity separately through the ordinary human/GitHub review process;
   **a JSON identity claim is not authentication**.
3. Read **all sentences**, including longer paragraphs and merged or expanded
   translations, in all 147 pairs. Check omissions, unjustified additions,
   negation and modality, authorization/security, default behavior, typed
   input/output contracts, numbers/units, exact API identifiers, references,
   provenance, scientific caveats and research-status qualifications.
4. For each source/target block or contiguous many-to-many group, record a
   specific equivalence/correction verdict and substantive explanation. Never
   mark an unresolved defect equivalent. Correct it, then review the new blob.
5. Preserve frozen research evidence, negative outcomes and verbatim archival
   hypotheses. Do not alter experimental science for superficial translation parity.

## Machine-readable evidence

Commit audits/ko-independent-review.json through a separate review PR. Its
schema version is 1. Supply independent_sentence_review_complete=true only
after every page and individual sentence has been examined. Include a top-level
reviewer object with nonempty identity, date and independence_basis.

Each page has path, en_blob, ko_blob, and a nonempty list of decisions.
Each decision carries en_indices, ko_indices, en_hashes, ko_hashes, verdict
(equivalent or corrected), and a substantive rationale. Obtain unit SHA-256
hashes from the generated audit inventory. For merged/split translations
declare contiguous many-to-many groups. Every block on both sides must be
covered exactly once, in order, including all sentences inside each block.

A valid 147-page ledger cannot be autogenerated from mechanical equivalence
signals, or fabricated to satisfy CI. Do not submit an example ledger as
completed evidence.

## Verification and closure

- Test the checker: python -m pytest -q tests/test_independent_translation_review.py
- Report coverage without success claims:
  python -m scripts.verify_independent_translation_review --json-out independent-review-status.json
- Strict gate:
  python -m scripts.verify_independent_translation_review --require-complete
- GitHub Actions Korean Translation Whole-Corpus Coverage Report additionally
  has workflow_dispatch input require_independent_review=true for this gate.

The strict script checks revision-pinned evidence coverage; it **does not
prove linguistic truth or authenticate a reviewer**. A separate reviewer
must actually inspect each sentence and approve the corresponding PR.

Do not check the last checkbox or close #1202 unless BOTH the strict evidence
gate and an authenticated independent editorial review are completed.
