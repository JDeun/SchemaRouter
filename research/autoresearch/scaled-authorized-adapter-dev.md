# #1428 Scaled authorized typed adapter DEV

This is an **author-visible synthetic development** benchmark, not independently
blinded confirmation, live provider quality, real user authentication,
tool execution, or downstream agent task success.

## Protocol

- Construct 100, 250 and 500 distinct capabilities with current
  OpenAPI and MCP parsers plus SQL/vector/graph native typed contracts.
  The original ten endpoints remain anchors and the remaining endpoints
  are deterministic synthetic parcel-ledger near-neighbor distractors.
- Compare frozen research V1 weights at pool K24 with frozen V2 weights
  at approved K24/K32/K40/K48/K56/K64 on the same 27 newly written
  English/Korean/Japanese queries.
- Score **after** the current SchemaRouter.retrieve_authorized() applies
  caller-supplied synthetic viewer/editor policy. Viewer is denied five
  baseline write endpoints and is denied audit_tag output visibility on
  local synthetic endpoints. Both rankers may only permute permitted IDs.
- Record per-case required endpoint and field presence, full field coverage,
  nonempty unsupported shortlist, bytes, latency, per-language and per-role
  breakdown, process peak RAM, source SHA-256 and commit.
- Verify query strings do not exactly duplicate the original 27-case
  local fixture. Shared intents, templates and common human authorship
  remain **contamination/independence limitations**, not resolved science.

The FULL authorized set is an upper-bound *membership* control only, not
FULL-agent task success. A nonempty no-fit shortlist is a retrieval
diagnostic, not proof of unsafe execution or false action acceptance.
The previously reported 1.5x latency relative criterion remains a
research decision threshold, not a certified production benchmark here.
