validation work before modifying source-bound security paths. This opt-in
diagnostic wraps unmodified original native fork functions for **one query
per condition** in the 500/5000 native CRM developer fixture with 33/64
additional SAME-root, SAME-ID approved status leaves.

For each exact registered source graph, it observes the private per-arm
indexed one-hop query count, internal over-cap responses, required input
contract inspections and per-pair flat original source record inspections.
The diagnostic then dynamically revokes extra status consumers through the
existing availability predicate on the SAME cached source index, verifies

strict public result must be `over_k_unranked` and reveal zero identities.
All reported metrics are **aggregate counts only**; never names, raw
source identities, user query text, private fields or provider response data.

profile-driven optimization, source-truth qualification, independent
publisher/permission gold, actual agent/model E2, or production SLO.

product change that keeps full live authorization, late field-scope and
