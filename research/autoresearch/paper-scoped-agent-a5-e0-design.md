# Scoped Algorithm 1 → existing fixed-K agent — A5 E0 design

**2026-10-26.** Continue issue #1560 and stacked Draft #1755. This records
the previously authorized bounded E0 vertical slice and the security boundary
revealed by the exact-head Python 3.12 regression. No new default product path.

## Intent and non-goals

Join one principal-scoped model `Understand(q)` response to the original
source-proven direct / named one- or two-hop graph planner, and then to the
existing `run_generated_episode` executor. Keep the host's authorization,
original route fingerprints, K=5 menu, immutable source witness, and
policy/data-scope checks in force at every stage. Do **not** introduce a
second agent/executor, infer arguments from model hints, flatten an unobserved
dependency DAG, change frozen #432, or claim independent publisher E2.

## Alternatives and chosen boundary

1. Return any `requires_arguments` direct receipt before graph lookup:
   **rejected**. A named target with source-typed dependency is prematurely
   treated as an unrelated host input; 1/2-hop and policy-mutation tests fail.
2. Always return graph `no_proven_hit` when no path exists: preserves the
   graph-only contract, but drops legitimately missing standalone scalar
   input from the A5 agent diagnostic.
3. **Chosen:** preserve graph API semantics exactly as in the approved
   `paper-named-graph-understand-e0-design.md`, then use a **separate,
   scoped A5 adapter** to recover one independently source-proven direct
   receipt only when all missing arguments are ordinary source-declared
   non-dependency parameters (`semantic_id is None`). Never recover from
   `over_k_unranked`, `ambiguous_paths` or a revoked source. Apply this same
   condition to a direct `requires_arguments` result when the model leaves
   `named_tools` empty: intent-only selection is not an alternate execution
   authority path.

## Observable acceptance

- Owner and principal verified direct `ready` route is disclosed to the
  existing fixed5 episode; its deterministic agent can make one real frozen
  fixture executor attempt (not independent real-provider E2).
- One missing source-declared scalar can be diagnosed as
  `request_arguments` without adopting any model-proposed value.
- A missing source-typed semantic identifier without a proved producer is
  **not** downgraded into a host scalar request and exposes no tool menu,
  whether named tools are supplied or omitted.
- Actual one-hop and two-hop source-proven paths classify as
  `request_observation` but expose zero tools, zero agent generations and
  zero tool attempts until independently authorized observation exists.
- Unknown/denied paths, model callback mutation, policy/source revocation,
  and mutation during an agent turn fail closed or enter the generic host
  empty-menu terminal. Supported empty-menu tasks do not pass optimistically.
- The named-target budget must not reveal whether a denied or field-hidden
  tool exists with over 32 endpoints. Apply principal visibility, current
  source/license and availability before counting the bounded graph target
  prefilter, then reverify all proof and source witnesses normally.
- Keep Draft #1755 stacked and unmerged, release #1356 on HARD HOLD, and
  publisher #1346 / independent agent #1477 externally gated.

## Verification boundary

`tests/test_paper_understood_graph_plan.py` is the graph-only semantic
contract. `tests/test_research_paper_scoped_agent_real_e0.py` uses actual
registry, principal, policy, scoped view, G5 graph and the original frozen
agent loop; only the model callback and agent response are deterministic.
These prove mechanics, not LLM language understanding, provider provenance,
commercial quality, or calibrated unsupported classification.
