## Measurements and scoring

Reference route/field pairs use the union of archived selected calls. Report reference tool recall, field recall (micro and macro across nonempty reference cases), all reference routes/fields contained, number of no-candidate positives, mean exposed routes/fields, per-category descriptive aggregate. Additional fields are not necessarily irrelevant and missing archived fields are not necessarily essential; do not label these scores ground-truth precision or task success. FULL is an exposure ceiling. Report no-reference cases separately, including nonempty menus, not classification success. Record any archived pairs absent from full schema explicitly. No gold-derived inputs, no silent dropping, no model tokens or wire-payload claims.

Context proxy: compact canonical UTF-8 bytes of entire result envelope, plus serialized search request for B/C (FULL has no discovery call); also report sum of serialized input/output schema bytes alone. No hidden omission of receipts. This measures a local representation, not actual LLM tokens, billing, prompt cache, request headers or provider response bytes. Each route metadata is exposed with the same original field annotations when present. CPU warm selection+serialization wall time (perf_counter_ns, median of 3 sequential executions per case/arm), p50/p95 across positive cases, separate one-shot build costs. A includes serialization rather than a fictional retrieval call. Repeat outputs must be identical. No actual tokenization, network, hardware throughput or task success in this phase. Retain case-level receipts (counts, coverage, selected route/field pairs, output hash, timing); report failures.

Engineering diagnostic thresholds (not decision-grade): 95% archived field and route recall, no loss of complete reference sets relative to FULL target; >=30% byte proxy reduction versus FULL is only useful with high recall. Compare C to B, not merely FULL. Do not choose a winner by cheap failures. If C simply equals existing RDF/field-projection C, no claim of independent algorithmic novelty. Gate C2 needs same-model full agent execution on new independently authored tasks, frozen policy/model/fixture and paired task success noninferiority -2pp, 95% CI and prespecified power, operational input/output tokens incl discovery, latency, argument validity, scope, annotation effort. Decision remains INCONCLUSIVE until adequate evidence; no merge/release.
