# Brand assets

SchemaRouter uses the **brace + routing hub** mark.

## Meaning

- **Curly braces** represent schema and structured contracts.
- **Central hub** represents routing and decision-making.
- **Three connected nodes** represent tools, endpoints, and fields converging through one validated execution boundary.
- **Teal accent** marks the trusted routing decision while graphite keeps the project visually aligned with developer infrastructure.

## Palette

| Token | Value |
| --- | --- |
| Graphite | `#1F2937` |
| Near black | `#111827` |
| Teal | `#14B8A6` |
| Bright teal | `#2DD4BF` |
| Light neutral | `#E5E7EB` |
| Off white | `#F8FAFC` |

## Files

- `schemarouter-mark-light.svg` — mark for light backgrounds.
- `schemarouter-mark-dark.svg` — mark for dark backgrounds.
- `schemarouter-lockup-light.svg` — horizontal mark + wordmark for light backgrounds.
- `schemarouter-lockup-dark.svg` — horizontal mark + wordmark for dark backgrounds.

Use the mark for favicons, avatars, and compact navigation. Use the lockup in README, documentation landing pages, and social graphics.

Do not stretch, rotate, recolor individual nodes independently, or add effects such as shadows/glows to the core mark.
